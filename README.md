## About This Repository

This repository is based on NVIDIA's [Learn OpenUSD](https://github.com/NVIDIA-Omniverse/LearnOpenUSD) repository and is maintained as a personal learning environment.

I am using the original course materials and examples to learn OpenUSD, experiment with the code, and build my own understanding of USD concepts. Any modifications, experiments, or additional examples in this repository are primarily for educational and personal learning purposes.

The original course content and materials belong to their respective authors and contributors. For the official learning content, please visit the [Learn OpenUSD documentation](https://docs.nvidia.com/learn-openusd/latest/index.html).
